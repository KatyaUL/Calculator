# Калькулятор

Консольная программа-калькулятор на Python 3.

## Возможности
- Сложение, вычитание, умножение, деление, возведение в степень
- Обработка ошибок ввода
- Обработка деления на ноль
- Статистика результатов и вычислений
- Поиск по ключевому слову в выражении

## Требования
- Python 3.10+
- ОС РЕДОС (или другой Linux)

## Установка и запуск
1. Клонируйте репозиторий (или скопируйте папку)
2. Создайте виртуальное окружение:
python3 -m venv venv
3. Активируйте окружение:
source venv/bin/activate
4. Запустите программу:
python main.py

## Алгоритм работы 

Ниже представлена блок-схема основной логики калькулятора:

```mermaid
graph TD
    A[Старт] --> B{Меню действий}
    B -->|1| C[Выполнить вычисления]
    C --> D[Ввод первого числа]
    D --> E[Ввод второго числа]
    E --> F[Ввод операции +, -, *, /, **]
    F --> G{Операция / и число2 == 0?}
    G -- Да --> H[Вывод: Ошибка деления на 0]
    G -- Нет --> I{Операция ** ?}
    I -- Да --> J[Возведение в степень]
    I -- Нет --> K[Вычисление результата]
    J --> L[Вывод результата]
    K --> L
    L --> B
    H --> B
    B -->|2| N[Показать историю]
    N --> O[Вывод списка записей]
    O --> B
    B -->|3| R[Очистить историю]
    R --> S[История очищена]
    S --> B
    B -->|4| U[Показать статистику]   
    U --> V[Вывод: Общее кол-во, Среднее значение, Максимальное значение, Минимальное значение]
    V --> B
    B -->|5| X[Поиск по истории]
    X --> Y[Ввод ключевого слова]
    Y --> Z[Вывод найденных записей]
    Z --> B
    B -->|0| W[Выход]
    W --> M[Конец]
